# Architecture Decision Records

One short file per decision: context, options considered, choice, consequences
(MADR template). Written when the decision happens; agents may draft an ADR by
mining the design conversation that already contains it.

Practice defined in docs/process/USESI-SDLC.md (Section 10; started at
migration task 2.8). PRs touching architecture-flagged paths (contracts,
schemas, cross-app dependencies, manifest dependency changes) require a linked
ADR. None recorded yet.
