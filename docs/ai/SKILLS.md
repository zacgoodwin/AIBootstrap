# Skill catalog

Packs (gstack) are host-installed by bootstrap; plugins install on
repo trust; project agents and skills live in .claude/. CLAUDE.md `## Routing`
covers the common paths.

## Pack skills (gstack, zstack)

The live skill listing injected into every session is the source of truth for
pack skills and their descriptions; it is always current. Don't duplicate it
here: a hand-maintained copy drifts on every pack update.

## Library (parked, not session-loaded)

Sorted by /agent-sort (2026-08-10): DAILY surfaces stay in .claude/skills/ and
.claude/agents/ and load every session; everything off-stack or situational is
parked in .claude/skill-library/ (148 skills) and .claude/agent-library/
(33 agents). Parked items are full, working skill/agent files — read them in
place for one-off use, or promote with `git mv` + `node tools/catalog-sync.mjs`
(recipe in the skill-library router). Child repos promote stack-matched items
at bootstrap (docs/ai/BOOTSTRAP.md Step 3). Provenance for synced items stays
in skills-lock.json regardless of bucket.
